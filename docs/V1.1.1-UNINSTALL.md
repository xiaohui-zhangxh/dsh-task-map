# v1.1.1 插件禁用/卸载清理与界面残留说明

> 日期：2026-11-05 ｜ 版本：1.1.1 ｜ 触发：用户反馈「在插件中心关闭任务地图插件后，左侧导航条和会话里的页签还在」

## 1. 原因分析

DSH 的客户端插件由 client-modules 在页面内挂载：插件中心关闭插件时，Host 移除 Loader entry，页面通过模块图同步（HMR）销毁插件 fiber，slot 注册（侧栏导航、会话页签）随之移除。

复现与验证结论（隔离实例）：

- 关闭插件时 **slot 层面的导航/页签能正确移除**（依赖 DSH client-modules 的 HMR 同步）；
- 但插件此前存在**全局 DOM 副作用残留**：`<html data-task-map-*>` 标记、注入的 `<style id="task-map-m2-style">`（未打 `data-plugin` 标记，client-modules 无法按插件清理）、`window.__TASK_MAP_M2__` 调试标记。这些残留会让「禁用」看起来没有完全卸载。
- 若关闭后界面仍残留导航/页签，通常是页面没有收到/没有应用模块图同步（例如页面加载时的 release 与 Host 当前 release 不一致、页面从旧进程缓存、或客户端 HMR 连接异常）；**刷新一次页面**即恢复，插件无法从被禁用侧反向驱动页面。

## 2. 修复（v1.1.1）

- 注入的样式打上 `data-plugin="@local/dsh-task-map"`，client-modules 禁用/卸载时可按插件清理；
- 插件 `apply` 注册 `ctx.effect(() => () => cleanupDom())`（无 effect 时退化为 `dispose` 事件），fiber 销毁时清理：
  - `<html>` 上的 `data-task-map-plugin` / `data-task-map-client-version` / `data-task-map-slots`；
  - 注入的 `<style id="task-map-m2-style">`；
  - `window.__TASK_MAP_M2__` / `window.__TASK_MAP_M0__` 调试标记；
- 组件内的 rAF / ResizeObserver / window 事件监听随 React 卸载自动释放；slot 注册由 `slots.inject` 的 effect 自动清理。
- `scripts/uninstall.sh` 与 README 补充说明：**禁用/卸载后如界面残留，刷新页面一次**；卸载脚本会清理 profile bundles/dependencies/node_modules 链接。

## 3. 验证（隔离实例，插件中心真实开关）

脚本：`tmp/e2e-work/disable-test2.cjs`；结果 **13 checks / 0 failed**：

| 步骤 | 断言 |
|---|---|
| 启用态 | 左侧导航「任务地图」存在、`<html>` 标记存在、样式存在、`window.__TASK_MAP_M2__` 已加载、会话有「任务地图」页签 |
| 插件中心点击「禁用」 | 导航移除、`data-task-map-*` 标记全部清除、注入样式移除、`window.__TASK_MAP_M2__` 清理、会话页签消失 |
| 重新启用 | 导航/样式/客户端标记恢复、会话页签恢复 |
| 二次禁用 | 无任何残留（幂等） |
| 全程 | 无页面错误 |

## 4. 使用建议

- **禁用/卸载步骤**：插件中心关闭开关（或 `./scripts/uninstall.sh`）→ **刷新 DSH 页面**（客户端模块热卸载在少数情况下可能未同步）。
- 判断是否彻底卸载（页面控制台）：

```js
document.documentElement.hasAttribute('data-task-map-plugin')   // 应为 false
!!document.getElementById('task-map-m2-style')                  // 应为 false
!!window.__TASK_MAP_M2__                                         // 应为 false
```

- 如刷新后仍在：完全退出并重启 DSH，再检查 `~/.dsh/profiles/desktop/package.json` 的 bundles/dependencies 是否已移除（`scripts/uninstall.sh` 会处理）。
