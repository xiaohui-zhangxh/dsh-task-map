# v1.0.1 单图模式（流程图 / 甘特图 一键放大与折叠）

> 日期：2026-11-05 ｜ 版本：1.0.1（基于 1.0.0 MVP）｜ 实现：`client.js`（m2-builder）｜ 验证：隔离实例 E2E 31 checks / 0 failed

## 1. 背景

大屏场景下同时展示「任务流程图 + 甘特图」会让两个图都偏小。v1.0.1 增加**单图模式**：一次只看一个图表，占满左侧可用高度，右侧详情/总览保留。

## 2. 使用

- 任务地图左栏：「执行轨迹 · 任务流程图」与「时间轴 · 任务/代理/事件/热度」面板标题栏右侧各有一个按钮：
  - **「⤢ 放大流程图」**：流程图占满左栏高度，甘特图折叠为仅标题栏；
  - **「⤢ 放大甘特图」**：甘特图占满左栏高度，流程图折叠为仅标题栏；
  - 单图模式下按钮变为 **「⇲ 恢复双栏」**（折叠面板的标题栏也保留该按钮），点击回到上下分栏；
- DOM 保留（隐藏不卸载），切换不丢回放时刻/选中任务/回放状态；
- 面板按钮支持键盘 Enter/Space，带 `aria-label`/`aria-pressed`。

## 3. 实现要点

- `layoutMode: 'both' | 'flow' | 'gantt'`（模块级 store，重挂载保留）；根节点 `data-tm-layout-mode`；面板 `data-tm-panel="flow|gantt"` + `data-tm-panel-collapsed`；按钮 `data-tm-panel-action="maximize-flow|maximize-gantt|restore-both"`。
- 布局：`.tm-main` 的 `grid-template` 随模式切换（both 按行数分配 40%/46%；flow `1fr auto`；gantt `auto 1fr`）；折叠面板 body/foot `display:none`。
- 尺寸自适应（无宿主 probe）：
  - 流程图：ResizeObserver 测容器，额外高度按 45% 节点高度（单节点最多 +96px）+ 55% 行距分配，viewBox 精确匹配；x 轴/节点宽度不变（不横向溢出）。
  - 甘特：`rowScale = clamp((目标高度−TOP)/(基础高度−TOP), 1, 2.6)` 放大任务/代理/事件/热度行距，时间映射不变；窗口化行数随高度重算。
- `useHostFitHeight` 改为**结构式测量**（`H = 滚动容器可视高 − 根节点顶部偏移 − 根节点之后兄弟内容高`），并新增窗口 `resize` 监听（rAF + 150ms 去抖）与 layoutMode 切换时重算：大屏/resize 后根视图自适应（1680×1050→2560×1440 根高 804→1194）。

## 5. 已知限制

- 流程图单图为「卡片增高 + 拉开行距」而非整体等比缩放（避免横向溢出/文字变形）；如更希望整体 zoom（接受横向滚动），调整 `stretchFlowLayout` 分配系数即可。
- 甘特 `rowScale` 上限 2.6×：任务极少（≤3）时单图下方可能仍有少量留白。
- 折叠用 `display:none`，DOM/滚动位置保留；极端浏览器可能重置折叠面板 scrollTop（不影响回放/选中）。
- 窄屏（<900px）单图模式已给 3 行 grid 兜底，但主要面向大屏验证。
- 测试：`client-smoke` 604 checks / `client-logic` 308 checks（含单图模式、resize 自适应、结构式 fit height 断言）。
