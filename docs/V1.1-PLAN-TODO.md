> 日期：2026-11-05 ｜ 版本：1.1.0 ｜ 契约：`STATE_VERSION=4`

## 1. 背景（用户反馈）

1. **流程图卡片点击后，hover 浮层跑到屏幕左上角**（截图见原始反馈）。

## 2. 修复 / 新增

### 2.1 流程图卡片浮层定位（bug fix）

- **根因**：流程图节点 `onFocus` 把 **FocusEvent** 传给 tooltip store，而 FocusEvent 没有 `clientX/clientY`（值为 0），浮层因此固定在 `left:0; top:0`（点击卡片会让节点获得焦点 → 触发 focus → 左上角）。
- **修复**：新增 `tooltip.showAtRect(rect, payload)`，`onFocus` 用节点 `getBoundingClientRect()` 计算浮层位置（节点的上方/左侧），并对 left/top 做视口 clamp；鼠标 hover 仍用鼠标坐标并同样 clamp。点击/键盘聚焦浮层都出现在节点附近，不再落到 (0,0)。

### 2.2 会话计划（todo）与团队任务并存（数据 + UI）

- **数据层**（`lib/derive.js`，STATE_VERSION 3→4）：
  - `state.plan`：无论是否有团队任务板，`todo/write` 都折叠为计划快照 `{ items:[{id,index,content,status,updatedAt}], counts, updatedAt, writeCount }`；
  - `view.plan`：`{ items, counts, updatedAt, writeCount, source:'todo', active }`；`active = 存在团队任务板`（同时存在时展示计划区块；只有 todo 时图/甘特本身就是 todo 降级任务，不重复展示）；
  - 团队任务板的图/甘特/基线/变更流语义不变；todo 降级模式的基线/变更流逻辑保留。
- **客户端**：总览新增 **「会话计划（todo）」** 区块 —— 标题 + `N 次计划更新` + 计数 chips（已完成/进行中/待处理）+ 清单（状态图标、内容截断、更新时间），只读展示；附说明「计划来自会话 todo；执行任务见左侧任务图」。data 属性：`data-tm-plan`、`data-tm-plan-item`、`data-tm-plan-status`、`data-tm-plan-counts`。

## 5. 已知限制

- 计划清单与团队任务暂不自动建立映射（同一事项在 todo 和执行任务里可能各出现一次，属预期：计划 vs 执行两个视角）。
- 计划区块只读，不提供编辑（产品口径：动态调整只走对话）。
- 无 todo 的会话不显示计划区块；只有 todo、无团队任务时图/甘特展示 todo 降级任务（不重复显示计划清单）。
