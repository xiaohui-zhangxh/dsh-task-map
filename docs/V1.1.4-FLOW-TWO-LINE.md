# v1.1.4 流程图卡片标题改为最多两行

> 日期：2026-11-05 ｜ 版本：1.1.4 ｜ 触发：用户反馈「流程图卡片的文字改为最多两行显示」

## 背景

流程图节点卡片的标题此前是单行渲染：`truncateText(task.subject, 16)` —— 固定截到 16 个字符 + 省略号。真实任务标题普遍更长（如「实现 Athena Port 控制面 M1（controller + STUN + UDP 中继 + TLS/WSS + SQLite）」），卡片上只能看到前 16 字，信息丢失严重。

## 改动

1. **标题最多两行**：节点标题从 SVG `<text>` 改为 `<foreignObject>` 内的 HTML 文本 + CSS `-webkit-line-clamp:2`，由浏览器原生换行并在超出两行时显示省略号；CJK、英文混排、短标题单行都表现正确，不再按字符数粗暴截断。
2. **统一卡片内部排版**：新增纯函数 `flowNodeLayout(nodeHeight)`（`client.js`，已导出到 `__test.utils` 供单测），返回标题块位置/字号/行高与负责人行位置，按卡片高度分三档：
   | 档位 | 适用 | 字号 / 行高 | 标题块 | 负责人行 |
   |---|---|---|---|---|
   | 标准 standard | 2 行内任务图（高 70） | 11.5px / 13 | y=27，高 26 | 贴底（高−7） |
   | 紧凑 compact | 3~4 行任务图（高 64） | 11px / 12 | y=23，高 24 | 贴底（高−6） |
   | 密集 dense | 5+ 行任务图（高 60） | 10.5px / 11.5 | y≈22，高 23 | 贴底（高−5） |
3. **行高/行距联动**：`computeFlowLayout` 同时上调卡片高度、下调行距，保持行步长基本不变（2 行内 70+50=120 与原 62+58=120 相同；3~4 行 64+30=94 与原 54+40=94 相同；5+ 行 60+24=84 与原 50+32=82，仅 +2/行），流程图总高只增加 +6~+26 SVG 单位，面板自适应/滚动逻辑不受影响。
4. **单图（拉伸）模式**：标题块随卡片高度自动向中线靠拢（`max(档位起点, 高/2 − 行高)`）；负责人行在高度 96→166 区间从「贴底」平滑过渡到 76% 位置（替换原先 >92 的硬跳档），大卡片不再突兀。
5. **信息不丢失**：完整标题仍由节点 `aria-label`、自定义 tooltip、任务详情提供；不重新引入原生 `<title>`（v1.1.2 约定）。

## 边界与说明

- **密集档为合成视图**：真实会话副本没有 17+ 任务样本，5+ 行密集档用「隔离实例投影缓存注入 19 任务」的方式验证渲染排版，只代表 UI 表现，不代表真实会话数据链路。
- 双栏模式下 2 行任务图 SVG 因 viewBox 变高会等比缩小约 3%（`preserveAspectRatio: meet` 受容器高度约束）；单图模式由 `stretchFlowLayout` 重新填充，不受影响。
- 极窄面板（<640px）下卡片字仍随 SVG 等比缩小，与改动前一致；密集档 10.5px 字在 1:1 缩放下可读，再缩小属已知取舍。
