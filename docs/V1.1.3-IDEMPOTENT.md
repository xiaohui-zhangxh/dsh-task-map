# v1.1.3 插件重复启用/热更新时的幂等修复

> 日期：2026-11-05 ｜ 版本：1.1.3 ｜ 触发：移动项目到 `~/Codes` 并重新安装后，插件 UI 消失；实机 health 显示工具列表重复注册

## 现象与排查

- 实机 `GET /task-map/api/health` 返回 `tools: ["task_map_ping","task_map_record_relation","task_map_ping","task_map_record_relation"]` —— **同一实例内工具被注册两次**；
- 隔离实例复现：在插件中心「关闭 → 启用」循环中，每次重新启用都会再注册一套工具（2→4→6…）；客户端 slot 注册也会重复，第二次启用后会话页签不再出现；
- 原因：插件启用/禁用/热更新时，DSH 可能对同一模块重复执行 `apply`，而插件此前**没有幂等保护**：每次都新增投影/工具/路由注册，未释放上一轮挂载；客户端侧同样重复 `slots.register`。

## 修复

- Host（`index.js`）：
  - 新增 `mountDisposers` 注册表，`apply` 开始时先 `resetMounts()` 释放上一次的投影/工具/路由 effect；
  - 工具按名称去重（`status.tools` 不再重复），路由/投影每轮只注册一次；
- Client（`client.js`）：
  - slot 注册按 slot 名去重：重复 `apply` 时先释放旧注册再注册；`cleanupDom` 同时释放全部 slot；
  - 保持「禁用后清理 html 标记/样式/window 调试对象」逻辑（v1.1.1）。

## 验证（隔离实例）

- 启动：health `tools` = 2 个（1 次注册）；
- 插件中心连续 5 轮「关闭 → 启用」：每轮 health `tools` 恒为 2 个（不再累加）；
- 每轮启用后打开会话：`对话 / 轨迹 / 任务地图` 页签正常出现；
- 全新加载 / 刷新页面：页签正常、`window.__TASK_MAP_M2__.version = 1.1.3`、无页面错误；
- `npm test` 全绿：derive 307 / host 35 / client-smoke 661 / client-logic 329。
