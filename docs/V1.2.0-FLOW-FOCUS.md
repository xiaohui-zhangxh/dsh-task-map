# v1.2.0 流程图连线流向 + 连线悬停聚焦 + 卡片点击聚焦 + 去掉点击外框

> 日期：2026-11-05 ｜ 版本：1.2.0 ｜ 触发：用户新增需求（连线流动方向 / 悬停连线聚焦两端 / 点击卡片聚焦相邻节点 / 去掉点击卡片的外框）

## 需求

1. 流程的连线有**流动方向**；鼠标划过某条线时，只聚焦显示该线**两端的节点**，其他节点灰度显示。
2. 点击一个流程卡片时，聚焦显示与卡片**相连的所有节点**，其他节点灰度显示。
3. **去掉点击卡片时显示的外框**。

## 现状与根因（改造前）

- 执行轨迹是一条把全部卡片中心串起来的**单条 polyline**（`.tm-route-base` + 进度实线 `.tm-route`），依赖/关系连线是二次曲线 + 箭头；既没有流向动画，也无法按「某一条线」取到两端节点做聚焦。
- 点击卡片后出现的「外框」不是插件画的选中描边（`tm-sel`），而是 **Chromium 对鼠标聚焦 SVG `<g tabindex="0">` 绘制的 UA 默认焦点框**（`outline: auto`，系统强调色、约 5px、圆角）；实测点击后 `document.activeElement` 为该 `<g>`、`matches(':focus')=true`、`computed outline = auto 5px rgb(0,95,204)`。
- `TaskFlow` 是 `React.memo` 组件，原实现选中态只通过 `selectionRef` 在帧更新器里改 class，**选中变化不会触发重渲染**，无法用来做「邻接节点灰显」。

## 方案

### 1. 连线流动方向

- **执行轨迹改为逐段渲染**：相邻任务中心之间一段，每段 4 层——
  - `.tm-route-base` 底色虚线（流向动画：`stroke-dashoffset` 负向循环，沿路径起点→终点流动）；
  - `.tm-route` 进度实线：逐段 `dasharray/dashoffset` 揭示（替代原先单条 path 的整体揭示），回放进度与轨迹头仍逐帧更新；
  - `.tm-route-flow` 流向光点：`stroke-dasharray:1.5 14.5` + 16 单位 `dashoffset` 循环动画，在已完成/未完成段上都可见流向；
  - `.tm-route-hit` 加宽透明命中层（12px，`pointer-events:stroke`），用于悬停/聚焦交互。
- **依赖/关系连线**：保留原虚线曲线与箭头；虚线态同样加 `dashoffset` 动画表示流向（ready 依赖为实线橙色，靠箭头指示方向）。新增加宽透明命中层 `.tm-edge-hit`（10px），解决 1.15~1.5px 细线难以精确悬停的问题。
- 流向动画仅对 **≤64 任务**的流程图开启（`FLOW_ANIMATE_LIMIT`），大图滚动场景不做上百条 path 的逐帧重绘；`prefers-reduced-motion` 下由既有全局规则统一关闭。
- 回放进度重写为分段计算：每段 `getTotalLength()`，按累计长度分配露出长度；轨迹头用对应段的 `getPointAtLength()` 定位。

### 2. 悬停连线聚焦

- 新增 `hoverEdge { from, to }` React state；纯函数 `computeFlowFocus(prep, hoverEdge, selectedId)` 统一计算聚焦集合：
  - `edge` 模式（悬停连线时）：焦点 = 该连线两端节点，仅该连线保持高亮；
  - `node` 模式（选中卡片时）：焦点 = 卡片自身 + 一跳直连节点（执行顺序/依赖/关系，双向），两端都在焦点集合内的连线保持高亮；
  - 悬停优先于选中；鼠标离开连线回退到选中聚焦。
- 节点灰显用 `data-tm-dim="true"` + CSS（`opacity:.26; filter:grayscale(1)`），不参与帧更新器的 class 写入（避免回放帧覆盖）；连线灰显 `tm-edge-dim`、聚焦线 `tm-edge-focus`。

### 3. 点击卡片聚焦

- `TaskFlow` 增加 `selectedId` prop（父组件 state），memo 组件随选中重渲染，邻接聚焦集合即时生效；点击已选中的卡片仍为取消选中（原 toggle 行为），聚焦随之清除。
- 选中卡片照旧联动右侧详情面板；灰显节点仍可悬停 tooltip / 点击切换聚焦。

### 4. 去掉点击外框

- CSS 由 `.tm-node:focus-visible{outline:none}` 改为 **`.tm-node:focus{outline:none}`**：鼠标点击的 `:focus` 不再绘制 UA 外框；
- 键盘可达性保留：`:focus-visible` 时仍用 `.tm-node:focus-visible .tm-node-box{stroke:var(--tm-accent);stroke-width:2.4}` 做可见聚焦指示（实测 Tab 聚焦 `focusVisible=true`、`outline=none`、描边 2.4px）。

### 5. 附带修复

- 依赖边 ready 态由 class `.tm-ready` 改为 `data-tm-ready` 属性：React 悬停重渲染会重写 `class`，曾导致 ready 依赖边在悬停瞬间回退成灰色虚线。
- 面板提示更新为「悬停连线聚焦两端 · 点击任务查看详情」。

## 边界与说明

- **关系分叉连线（relation）无真实样本**：隔离实例的真实会话副本没有 relation 边；relation 连线与依赖连线共用同一套命中层/聚焦逻辑（`computeFlowFocus` 单测覆盖），未做真机 relation hover 截图。
- **>64 任务**关闭流向动画（性能保护），命中/聚焦仍可用；该分支由 client-smoke 的 65 任务渲染断言覆盖，未做大图 E2E。
- 连线命中层加宽到 10~12px；多条线交叉处按 DOM 层级择优（依赖/关系命中层在轨迹层之上）。
- 灰显节点未被禁用交互：仍可悬停查看 tooltip、点击切换聚焦。
