# v1.1.2 移除原生 title 提示（统一使用自定义 tooltip）

> 日期：2026-11-05 ｜ 版本：1.1.2 ｜ 触发：用户反馈「流程图节点 hover 时出现浏览器原生 title 提示，和自定义 tooltip 重叠」

## 背景

流程图节点 `<g>` 内带有 SVG `<title>`（无障碍/悬停文本），浏览器会在悬停时显示**原生白色提示**，与插件自己的深色 tooltip 重叠，观感差且信息重复。

## 修复

- 移除流程图节点的 SVG `<title>`（节点的 `aria-label` 仍提供完整可访问标题）；
- 移除各 DOM 元素上的原生 `title` 属性（统计 chips、回放按钮/倍速、返回按钮、依赖/支线 chips、变更记录行、执行过程行、计划项、等待拆解行、变更计数 pills、成员 pill、会话标题/时间等），统一改为：
  - 需要的可访问名称走 `aria-label`；
  - 详细信息走插件自定义 tooltip / 详情面板；
- 自定义 tooltip（`data-tm-tooltip`）保留，hover/focus 行为不变。

## 验证（隔离实例）

- 任务地图根节点内 `title` 属性数量 **0**、`svg title` 数量 **0**；
- 节点 `aria-label` 仍存在（完整标题）；
- hover 节点 → 自定义 tooltip 正常显示；
- 无页面错误。结果 **6 checks / 0 failed**；截图 `docs/v112-no-native-title.png`。
- `npm test` 全绿：derive 307 / host 35 / client-smoke 661 / client-logic 329。

## 说明

原生 title 提示全部移除后，超长文案的完整内容可在任务详情/计划区块等位置查看；不再依赖浏览器原生 tooltip。
